## Sobre o Projeto

Sistema desenvolvido em C# para monitoramento da biodiversidade marinha do Arquipélago de Fernando de Noronha.

O projeto foi desenvolvido como Atividade Extensionista do curso de Análise e Desenvolvimento de Sistemas da UNINTER, com foco na catalogação de espécies marinhas e acompanhamento da saúde dos recifes de coral.

---

##  Funcionalidades

- Cadastro de espécies marinhas
- Relatório de biodiversidade
- Relatório de saúde dos corais
- Área restrita para pesquisadores
- Registro de observações
- Persistência de dados com SQLite
- Recuperação de dados após reinicialização do sistema
